# 路线图

接下来要做的事，以及和 Windows 11 还差在哪里。原则不变：**不增加常驻程序、不多占内存和存储**；
做不到的宁可不做，或者只在用到时才运行。

## 下一次更新

### Win11 风格的任务管理器

现在 Ctrl+Shift+Esc 打开的是 Xfce 自带的 `xfce4-taskmanager`：能看进程、结束程序，但界面不像 Win11，
也没有「性能」「启动应用」这些页面。

候选方案（按开销从小到大）：

| 方案 | 开销 | 说明 |
|---|---|---|
| 给 `xfce4-taskmanager` 写 GTK 样式 | 0 | 只能改颜色、圆角、间距，布局还是原来的 |
| 自己写一个轻量的 Python + GTK3 任务管理器 | 只在打开时运行 | 左侧导航（进程 / 性能 / 启动应用），读 `/proc`；「启动应用」页直接管理 `~/.config/autostart`（和 `l4c optimize --ram` 用同一套 Hidden=true 机制） |
| Mission Center 等现成程序 | 依赖 GTK4 / libadwaita，约 100 MB+ | 界面最接近 Win11，但对 32G eMMC 和 4G 内存太重 |

倾向第二种：打开时才占内存，关掉就释放。
