# 快捷键表

Chromebook 键盘上的 **搜索键（🔍，左手小指位置）就是 Windows 键**，下表中写作 Win。

## 和 Windows 11 一样的快捷键

| 快捷键 | 功能 |
|---|---|
| Win（单按） | 开始菜单 |
| Win+S | 搜索应用 |
| Win+E | 文件管理器 |
| Win+D / Win+M | 显示桌面 |
| Win+L | 锁屏 |
| Win+I | 设置 |
| Win+R | 运行 |
| Win+V | 剪贴板历史 |
| Win+X | 关机 / 重启 / 注销 |
| Win+P | 外接显示器 / 投影 |
| Win+Shift+S | 框选截图（复制到剪贴板） |
| PrtSc（截图键） | 截图工具 |
| Win+1…9 | 打开任务栏上第 1…9 个应用 |
| Win+Tab | 切换窗口 |
| Alt+Tab / Alt+Shift+Tab | 切换窗口 |
| Alt+F4 | 关闭窗口（Alt + 顶排第 4 个键） |
| Ctrl+Shift+Esc | 任务管理器 |
| Ctrl+Alt+Delete | 注销 / 关机（Chromebook 上用 Ctrl+Alt+退格） |
| Win+空格 / Ctrl+空格 | 开关中文输入法 |
| Shift | 中文输入法内切换中 / 英文 |

## 分屏（贴靠）

| 快捷键 | 功能 |
|---|---|
| 把窗口拖到左 / 右边缘 | 左半屏 / 右半屏 |
| 把窗口拖到顶部 | 最大化 |
| Win+← / Win+→ | 左半屏 / 右半屏 |
| Win+↑ | 最大化 |
| Win+↓ | 最小化 |
| Win+Alt+← / → | 左上 / 右上 1/4 屏 |
| Win+Alt+Shift+← / → | 左下 / 右下 1/4 屏 |
| 双击标题栏 | 最大化 / 还原 |

## 虚拟桌面

| 快捷键 | 功能 |
|---|---|
| Win+Ctrl+← / → | 切换到上一个 / 下一个桌面 |
| Win+Shift+← / → | 把当前窗口移到上一个 / 下一个桌面 |

## Chromebook 键盘专用

| 按键 | 作用 |
|---|---|
| 顶排：返回 | 浏览器后退（Alt+←） |
| 顶排：刷新 | F5 刷新 |
| 顶排：全屏 | F11 全屏 |
| 顶排：窗口概览 | 切换窗口 |
| 顶排：亮度 / 静音 / 音量 | 和原来一样 |
| 搜索键 + 顶排第 1…10 个键 | F1 … F10 |
| 搜索键 + `-` / `=` | F11 / F12 |
| Alt + 退格 | Delete |
| Alt + ↑ / ↓ | PageUp / PageDown |
| Ctrl + Alt + ↑ / ↓ | Home / End |
| Alt + 搜索键 | 大写锁定 CapsLock |

> 顶排按键的实际顺序由 `l4c keyboard` 读取本机键盘信息自动生成，可用 `l4c info` 查看。
> 映射只作用于内置键盘，外接 USB / 蓝牙键盘保持原样。
